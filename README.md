# Joking
Joking is a terminal CLI tool that speeds up daily testing of chatbots, GenAI apps, and language models. It offers text alteration, Portuguese/English to Zulu translation, and encoding into binary, Morse code, Caesar cipher, Base64, and Hex, all through a clean, menu-driven interface.
